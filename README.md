# PC Optimization Suite

Комплексное решение для оптимизации ПК с Windows для максимальной производительности в пользовательском режиме.

## 🚀 Возможности

- **Оптимизация системы** - общие настройки Windows для производительности
- **Оптимизация служб** - отключение ненужных служб Windows
- **Оптимизация сети** - настройка сетевых параметров для минимальной задержки
- **Оптимизация видеокарты** - настройка NVIDIA/AMD для максимальной производительности
- **Игровая оптимизация** - специальные настройки для игр

## 📋 Требования

- Windows 10/11
- Права администратора
- PowerShell 5.0 или выше

## 🛠️ Установка и использование

### Быстрый старт

1. **Скачайте все файлы** в одну папку
2. **Запустите PowerShell от имени администратора**
3. **Выполните команду:**
   ```powershell
   .\scripts\run_all_optimizations.ps1
   ```

### Выборочная оптимизация

```powershell
# Только для игр
.\scripts\run_all_optimizations.ps1 -GamingOnly

# Только сеть
.\scripts\run_all_optimizations.ps1 -NetworkOnly

# Только видеокарта
.\scripts\run_all_optimizations.ps1 -GPUOnly

# Только службы
.\scripts\run_all_optimizations.ps1 -ServicesOnly

# Только система
.\scripts\run_all_optimizations.ps1 -SystemOnly
```

### Индивидуальные скрипты

```powershell
# Общая оптимизация системы
.\scripts\optimize_system.ps1

# Оптимизация служб
.\scripts\optimize_services.ps1

# Оптимизация сети
.\scripts\optimize_network.ps1

# Оптимизация видеокарты
.\scripts\optimize_gpu.ps1

# Игровая оптимизация
.\scripts\optimize_gaming.ps1
```

## ⚠️ Важные предупреждения

### Перед использованием:
- **Создайте точку восстановления** (скрипт делает это автоматически)
- **Закройте все программы** перед запуском
- **Убедитесь в стабильности системы** после изменений

### Что изменяется:
- Отключаются ненужные службы Windows
- Настраиваются параметры реестра
- Изменяются сетевые настройки
- Оптимизируются настройки видеокарты
- Настраиваются приоритеты процессов

## 🔧 Детальная оптимизация

### 1. Системные службы
Отключаются следующие службы:
- Windows Search
- Superfetch/SysMain
- Windows Update (временно)
- Background Intelligent Transfer Service
- Windows Error Reporting Service
- Telemetry services
- OneDrive
- Windows Defender (если используется сторонний антивирус)

### 2. Сетевые настройки
- Отключение QoS Packet Scheduler
- Настройка TCP для игр
- Оптимизация DNS
- Отключение ненужных протоколов

### 3. Видеокарта
**NVIDIA:**
- Установка режима "Maximum Performance"
- Отключение ненужных функций
- Настройка приоритетов GPU

**AMD:**
- Включение Radeon Boost
- Настройка Radeon Anti-Lag
- Оптимизация параметров

### 4. Игровые настройки
- Включение Game Mode
- Отключение Game DVR
- Настройка приоритетов для игр
- Оптимизация DirectX
- Настройка звука и периферии

## 📊 Мониторинг производительности

### Рекомендуемые инструменты:
- **MSI Afterburner** - мониторинг GPU
- **HWiNFO64** - мониторинг системы
- **LatencyMon** - проверка задержек
- **UserBenchmark** - тестирование производительности

### Метрики для измерения:
- FPS в играх
- Задержка ввода (input lag)
- Температура компонентов
- Использование CPU/GPU/RAM
- Задержка сети (ping)

## 🔄 Откат изменений

### Автоматический откат:
1. Откройте "Восстановление системы"
2. Выберите точку "PC Optimization - Before Changes"
3. Следуйте инструкциям

### Ручной откат:
1. Включите отключенные службы
2. Сбросьте настройки реестра
3. Восстановите сетевые настройки
4. Сбросьте настройки видеокарты

## 🆘 Устранение проблем

### Частые проблемы:

**Система работает медленно:**
- Проверьте температуру компонентов
- Убедитесь в стабильности разгона
- Проверьте использование диска

**Игры не запускаются:**
- Обновите драйверы видеокарты
- Проверьте настройки DirectX
- Восстановите настройки видеокарты

**Проблемы с сетью:**
- Сбросьте сетевые настройки
- Проверьте настройки DNS
- Перезапустите сетевые службы
