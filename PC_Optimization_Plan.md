# План оптимизации ПК для максимальной производительности в пользовательском режиме

## Обзор
Этот план фокусируется на оптимизации Windows для максимальной производительности в пользовательском режиме, исключая изменения в ядре системы.

## 1. Оптимизация BIOS/UEFI
### Настройки для максимальной производительности:
- **CPU Settings:**
  - Включить все ядра процессора
  - Отключить энергосбережение (C-States, P-States)
  - Установить максимальную частоту CPU
  - Включить Turbo Boost/Precision Boost

- **Memory Settings:**
  - Включить XMP/DOCP профили
  - Установить максимальную частоту RAM
  - Уменьшить тайминги памяти (если стабильно)
  - Включить dual-channel режим

- **Power Management:**
  - Установить High Performance режим
  - Отключить все энергосберегающие функции
  - Включить HPET (High Precision Event Timer)

## 2. Оптимизация Windows Services
### Отключение ненужных служб:
- Windows Search
- Superfetch/SysMain
- Windows Update (временно для игр)
- Background Intelligent Transfer Service
- Windows Error Reporting Service
- Telemetry services
- Cortana
- OneDrive
- Windows Defender (если используется сторонний антивирус)

## 3. Оптимизация сети
### Настройки для минимальной задержки:
- Отключить QoS Packet Scheduler
- Настроить приоритеты сетевых адаптеров
- Отключить ненужные сетевые протоколы
- Настроить DNS (использовать быстрые DNS серверы)
- Отключить IPv6 (если не нужен)

## 4. Оптимизация видеокарты
### NVIDIA:
- Установить режим "Maximum Performance"
- Отключить VSync в драйверах
- Включить G-Sync (если поддерживается)
- Настроить приоритет GPU для игр
- Отключить ненужные функции (Ansel, ShadowPlay если не используется)

### AMD:
- Включить Radeon Boost
- Настроить Radeon Anti-Lag
- Отключить ненужные функции
- Установить максимальную производительность

## 5. Оптимизация звука
- Отключить ненужные аудио устройства
- Установить минимальную задержку аудио
- Отключить звуковые эффекты Windows
- Настроить приоритет аудио для игр

## 6. Оптимизация периферии
- Настроить мышь для максимальной частоты опроса (1000Hz)
- Отключить ускорение мыши
- Настроить клавиатуру (отключить задержки)
- Настроить геймпад (если используется)

## 7. Оптимизация Steam и игр
- Отключить Steam Overlay (если не нужен)
- Включить Steam Input
- Настроить приоритет процессов для игр
- Отключить ненужные Steam функции

## 8. Оптимизация планировщика задач
- Удалить ненужные задачи
- Настроить приоритеты для игр
- Отключить автоматические обновления
- Настроить дефрагментацию диска

## 9. Оптимизация дисков
- Включить TRIM для SSD
- Отключить индексацию дисков
- Настроить кэширование дисков
- Отключить автоматическую дефрагментацию для SSD

## 10. Оптимизация реестра
- Отключить ненужные автозагрузки
- Настроить приоритеты процессов
- Оптимизировать параметры памяти
- Отключить ненужные анимации Windows

## 11. Мониторинг и тестирование
- Использовать MSI Afterburner для мониторинга
- Тестировать стабильность после изменений
- Измерять FPS и задержки
- Проверять температуру компонентов

## 12. Безопасность
- Создать точку восстановления перед изменениями
- Сохранить резервные копии важных настроек
- Тестировать изменения поэтапно
- Иметь план отката изменений
